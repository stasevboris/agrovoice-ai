# Пример задания локальному агенту

Прочитай PROJECT_GUIDE.md и указанный файл отчёта. Создай один документ
docs/agent-output/current-model-summary.md: какие эксперименты закончены,
какие ещё идут, какие метрики реально подтверждены и какие классы слабы.
У каждого численного утверждения укажи исходный файл/ключ JSON.
Не выполняй обучение, не загружай данные, не устанавливай зависимости.
Не изменяй существующие исходники, датасеты, веса и результаты.
Если отчёт не содержит нужного значения, напиши «данных нет».
В конце перечисли созданные файлы и способ проверки.
