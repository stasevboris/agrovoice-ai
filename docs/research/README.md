## Архив исследования 3–4 октября 2026

Ниже исторические решения. Они не описывают текущую очередь обучения или мобильную LLM; модели для локального программирования — отдельная задача.

Условия: Ryzen 7 5700X / RX 9060 XT 16 ГБ / RAM 32 ГБ; культуры картофель, томаты, огурцы; публикация как физлицо Беларуси, бесплатно.

| Вопрос | Документ | Практическое решение |
|---|---|---|
| Какие другие YOLO проверить | [Исследование версий4 октября](YOLO_ALTERNATIVES_2026-10-04.md) | Сейчас10YOLO26s + лучший26n;26m как следующий кандидат качества,11s/v9s/v10s контроль,12/13 резерв,27 unreleased |
| Чем пополнить слабые классы | [Датасеты и следующий эксперимент](DATASETS_NEXT_TRAINING_2026-10-03.md) | 27 записей, включая копии и источники с непроверенным доступом. Первые кандидаты: полевой здоровый картофель D01/D02, повреждения клеща D06, томатные болезни D09/D10. Не менять текущую study10_v2 |
| Какую локальную модель взять | [Hugging Face и память](LOCAL_CODING_MODELS_2026-10-03.md) | Сначала Qwen3.5-9B Q4_K_M; резерв Qwen2.5-Coder-14B Q4_K_M. Семь семейств/репозиториев, размеры реальных GGUF, без вымышленных tokens/s |
| Как подключить агента | [Инструкция и шаблоны](LOCAL_AGENTS_SETUP_2026-10-03.md) | LM Studio/Vulkan + OpenCode, альтернатива Cline/Continue; Aider для ограниченных правок. Шаблоны не активированы |
| Как выложить приложение | [Google Play и другие каналы](ANDROID_STORES_PUBLICATION_2026-10-03.md) | Подписанный APK для демонстрации; Play $25 и минимум 12 тестировщиков/14 дней для нового личного аккаунта; RuStore как второй канал |
