Решение Бориса от 16.10: **поддерживаются все культуры**, а не только картофель, томат и огурец. Обучение — на арендованной RTX 5090, домашнюю RX 9060 XT под длинные обучения не занимать.

Обозначения в поле «Кто»: **агент** — можно делать без Бориса; **Борис** — нужен человек (телефон, GPU, решение, доступ, эксперт); **агент+Б** — агент готовит, Борис подтверждает.

## 0. Цель продукта (что сдаём в мае 2027)

Офлайн-приложение для Android и сервер хозяйства:
1. Агроном фотографирует лист голосом, с кнопки гарнитуры или с экрана. Модель на телефоне выдаёт **культуру и состояние листа** (49 классов, 15 культур) с уровнем уверенности, рамками и пометкой «предварительно».
2. По запросу «чем лечить» приложение показывает и озвучивает меры по справочнику: препараты из Госреестра РБ с источником и годом, агротехнику, а при дефиците питания — подкормку.
3. Осмотр сохраняется в журнал: фото, GPS, участок, ряд, заметка голосом, оценка «верно/неверно». Когда появляется сеть, журнал синхронизируется с сервером.
4. Сервер: веб-панель для главного агронома (таблица, карта, подтверждение специалистом, выгрузка XLSX) и публикация новых версий справочника и модели.

## Этап 4. Справочник СЗР (1 декабря – 10 января)

### K-01 Формат справочника — **агент**
`kb/kb_v1.json` + JSON Schema: `disease{code, crop, name_ru, latin, kind, symptoms, conditions, prevention[], agrotech[], treatments[], sources[], status: draft|verified, verified_by, year}`; `treatment{product, active_substance, rate, unit, max_treatments, waiting_days, hazard_class, bees_class, registered_in: BY, register_year, note}`. Для `nutrition` — `fertilization[]` вместо препаратов. Валидатор + тест.

### K-02 Наполнение — **агент** (черновик) + **специалист** (проверка)
Порядок: картофель → томат → огурец → яблоня → земляника → вишня → малина → перец → тыква → кукуруза → соя → виноград → голубика → персик; апельсин — только описание, без препаратов («не выращивается в РБ»). Источник препаратов — актуальное издание Государственного реестра СЗР и удобрений РБ. Рекомендации — РУП «Институт защиты растений». Агент делает черновик **только** со ссылками на источник; неподтверждённое — `status: draft`.

### K-03 Экран и голос — **агент**
Экран «Справочник» (поиск, культура → болезнь); из результата — кнопка и команда «чем лечить» → 1–3 препарата + агротехника; озвучка только для `verified`, иначе «Справка не проверена специалистом, смотрите текст». Дисклеймер «сверьтесь с этикеткой препарата». **Готово, когда:** сценарий «фото → чем лечить» работает офлайн.
