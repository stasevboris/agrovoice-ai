# INT8 детектора: качество и скорость на Redmi

Исходные числа, SHA файлов, условия и результаты проверок — в [report.json](report.json).
Это проверка M-11/R-05 на пилоте YOLO26n; новые веса в APK не установлены.

| Вариант | field-val mAP50–95 | Размер ONNX, байт | Медиана инференса на Redmi, мс |
|---|---:|---:|---:|
| YOLO26n FP32 | 0,287725 | 9 689 219 | 137,81 |
| INT8, вся голова | 0,053829 | 3 039 008 | Не повторялся в этом замере |
| INT8, выходная голова FP32 | 0,261526 | 3 025 881 | 79,00 |

Квантизация QDQ использует только train. Полная квантизация головы резко ухудшила
качество: координаты и оценки классов имеют разные масштабы. Сохранение выходных
операций и последних свёрток головы в FP32 уменьшило потерю, но не устранило её.
Решение: оба варианта остаются экспериментальными. Ускорение само по себе
не является основанием заменить действующую модель.

Телефон: Redmi Note 7, Android 13, ORT 1.30 CPU, четыре intra-op потока,
пять прогревов и тридцать измерений на модель. Случайный вход одинакового seed;
замер от вызова `session.run` до получения результата. Предобработка,
декодирование, камера и интерфейс сюда не входят. Исходные времена сохранены.
SHA связывают телефонный замер с файлами из отчётов качества.

PSS относится ко всему тестовому процессу. Устройство питалось по USB:
расход батареи не измерен. BatteryService сообщал 27 °C до/после;
ThermalService не предоставил температурных датчиков. Это не измерение
температуры корпуса или длительного нагрева. Test не использован;
неполнота классов пилота и ограничения field-val сохраняются.

Воспроизведение: `quantize_detector_int8.py --onnx <FP32> --config <pilot/config>
--out <новый каталог в runs>`, затем `OnnxBenchmarkDeviceTest` только в пакете
`.verification`. Кандидаты размещаются в `files/benchmark`; аргументы
instrumentation: `-e models a.onnx,b.onnx -e runs 30`. Установка — `adb install -r`
тестового APK, запуск — `adb shell am instrument`, без `connectedDebugAndroidTest`.
Публикация моделей по-прежнему проходит через `prepare_model_release.py`.
