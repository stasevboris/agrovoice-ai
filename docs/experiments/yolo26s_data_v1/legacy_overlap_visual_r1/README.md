# Визуальная проверка наследованных похожих кадров

Просмотрены все37 пар на10 листах; исходные74 чтения JPEG проверены по prepared SHA из старого manifest. Во всех парах видны версии одной исходной фотографии (пересжатие/размер/текстовое оформление). Это подтверждение тождества сцены, не экспертная диагностика культуры или состояния.

- Пересечения разных исторических разделов: **9 пар**, 18 записей.
- Различия наборов ID-классов: **19 пар**. Случаи включают классы картофеля/томата и различные болезни. Различия наборов классов требуют проверки конкретных объектов/рамок; правильный диагноз не выбирался по фотографии.
- Всего затронуто **71 уникальных исторических изображений**. На этапе новой сборки они отмечены для карантина до проверки аннотаций; старые файлы/метки/split не менялись. Даже временное удержание всех этих train-кадров сохраняет ненулевую поддержку каждого исходного класса0..28: числа в `visual_adjudication.json`.

Исторические оценки N/S/M необходимо показывать с новым ограничением независимости выборок. Для новой серии все производные одного изображения объединять до разбиения; старый test не подбирать и не использовать как единственное доказательство улучшения.
