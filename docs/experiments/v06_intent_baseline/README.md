# V-06: понимание команд без обучения (19.10.2026)

Сравнение на `ml-pipeline/assistant/scenarios.json` (авторские синтетические русские фразы, не записи людей и не выход ASR). Обе строки проходят через один исполнитель `ActionPolicy` в состоянии сценария. Команда: `gradlew testDebugUnitTest --tests *RulesBaselineTest` (файлы пишутся в `app/build/reports/v06/`, сюда скопированы).

| Способ | Выполнено верно (train / val / test) | Ложные выполнения на фразах отказа, уточнения и диктовки |
|---|---|---|
| Точные фразы приложения 0.18 — [rules_exact_phrases.json](rules_exact_phrases.json) | 0/104 · 0/14 · 0/20 | 0/34 · 0/10 · 0/19 |
| Правила свободных фраз `FreeSpeech` — [rules_free_phrases.json](rules_free_phrases.json) | 104/104 · 14/14 · 19/20 | 0/34 · 0/10 · 0/19 |

Как понимать:

- Точные фразы безопасны, но не понимают ни одной перефразировки корпуса. В режиме грамматики Vosk такие фразы и не будут распознаны.
- `FreeSpeech` написан при видимых всех частях корпуса, поэтому его числа — проверка разработки, **не независимый тест** и не точность на людях. Отдельные свежие фразы в `FreeSpeechTest` сразу нашли две ошибки обобщения («двадцать первый», повтор шага) — ожидать, что на живой речи результат будет ниже.
- Ошибки распознавания Vosk без грамматики сюда не входят. Режим «Свободная речь» в приложении экспериментальный и выключен по умолчанию.
- Intent-классификатор и малая LLM **не сравнивались**: обучение классификатора на домашнем ПК требует команды Бориса; LLM-прогон ещё не выполнен. Независимый набор фраз и говорящих — V-05/V-08.
