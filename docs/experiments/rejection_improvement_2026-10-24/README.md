# Улучшение отказа: фиксированная S + DINOv2/MLP

Получен экспериментальный кандидат, снижающий принятие неизвестных растений и FP
при сохранении ≥95% правильных ответов S на calibration, audit и историческом test.
Порог выбран только по calibration; на Redmi проверены ONNX и чистый инференс.
В рабочий APK цепочка не внедрена. Болезни этим опытом не валидированы.

Все числа: [сводка](report.json), [исследование](study_report.json),
[фиксированный test](frozen_test_report.json), [reference APK](apk_reference_report.json).

## Изменение и протокол

Жёсткое совпадение argmax культуры отклоняло правильные ответы S даже при пороге 0.
Вместо него отдельно проверены оценка неизвестности и парный score культуры S/reject.
Проверяющий модуль только удаляет ответ; культуру или диагноз S он не заменяет.

Проверены 13 сочетаний: прежние головы с двумя score, KNN-контроли и четыре новые
головы по 40 эпох, seed20261024, AdamW, batch256, нормализованные frozen-признаки ×10,
sqrt-inverse class weights, вес известных field-примеров ×2. План и LR зафиксированы
до результатов в [PLAN.md](PLAN.md). S и backbone не переобучались.

Финалист: **DINOv2-small CLS → нормализация → MLP128 → logits культур/reject**.
Score = `sigmoid(logit[культура S] − logit[reject])`; порог `0.9958845687447002`.
Это не вероятность правильности болезни. Выбор — только calibration: сохранить
≥95% TP S, не увеличить FP и принятие ни одного unknown-источника; затем уменьшать
среднее принятие unknown. Один финалист прошёл audit, затем фиксированный test.
После просмотра audit/test порог не менялся и другие финалисты не выбирались.

## Результаты отказа

| Раздел | Правильные культура + рамка: S → цепочка | Сохранено TP S | FP: S → цепочка | Фасоль | DeepWeeds |
|---|---:|---:|---:|---:|---:|
| Calibration | 484 → 462 | 462/484 | 335 → 259 | 53/59 → 0/59 | 534/1318 → 43/1318 |
| Audit | 428 → 407 | 407/428 | 266 → 217 | 63/74 → 0/74 | 85/263 → 8/263 |
| Test | 350 → 340 | 340/350 | 165 → 133 | 102/128 → 0/128 | 427/1489 → 0/1489 |

На audit сохранено около 95,1% TP S — запас небольшой; на test около 97,1%.
**Потери неодинаковы по культурам:** на audit соя 11→8 правильных ответов,
голубика 49→39, картофель 24→21. На test томат 131→123 и перец 18→17.
Полная [разбивка](per_crop_report.json) сохраняет знаменатели. Поэтому общие 95%
не являются допуском для каждой культуры; это дополнительное основание
сохранить экспериментальный статус. Порог по этой разбивке не перенастраивался.
Предметы: calibration 2/3 → 1/3, audit 0/2 → 0/2, test 0/6 → 0/6.
Предметов слишком мало для устойчивой оценки. Ноль ответов на этих test-растениях
не доказывает нулевой риск на других видах; кадры не считаются независимыми
полевыми наблюдениями для произвольных статистических интервалов.

Фиксированная APK дополнительно прогнана как описательный reference на том же test;
это сравнение не использовалось для перенастройки модели:

| Система | Верные культура + рамка / GT | FP | Precision | Recall | F1 |
|---|---:|---:|---:|---:|---:|
| S из APK | 329/452 | 173 | 0,6554 | 0,7279 | 0,6897 |
| Новая S | 350/452 | 165 | 0,6796 | 0,7743 | 0,7239 |
| Новая S + DINO/MLP | 340/452 | 133 | 0,7188 | 0,7522 | 0,7351 |

У APK приняты предметы 2/6, фасоль 100/128, DeepWeeds 484/1489;
у цепочки — 0/6, 0/128, 0/1489. Precision/F1 относятся к протоколу культуры/рамки,
не к диагнозу. FP включают дубли, неверные культуры и возможные неразмеченные листья.

## Ограничения и следующий шаг

Исторический PlantDoc test имеет ограничения split/почти-дубликатов; S выбиралась
на прежнем field-val. Здесь нет полевых GT огурца/апельсина. Unknown-метки слабые,
сцены могут содержать другие растения. Нового независимого полевого test нет.
Точность состояния/болезни, в том числе неизвестных состояний известной культуры,
не проверена. Нельзя объявлять проблему уверенных ошибочных диагнозов решённой.

Дальше — экспериментальный lab-путь S → crop → verifier → объяснимый отказ,
проверка всей предобработки и стоимости нескольких листьев. DINO добавляет около
0,5 с **на каждый лист** и 88,7 МБ; дистилляция в MobileNet — отдельный будущий опыт.
Нужны новые сцены, предметы, виды, свет/тень и подтверждённые состояния. Параметры
не подбирать повторно по уже просмотренным audit/test. Рабочие веса APK сохранены.
