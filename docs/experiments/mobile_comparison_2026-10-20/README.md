# Сравнение действующей модели и пилотов на одинаковых кадрах

Полные результаты, SHA моделей/разметки, команда и знаменатели —
[report.json](report.json). Исходные предсказания сохранены в `runs/`, их SHA
записан в отчёте. Test не использован, порог 0,25 не подбирался по результатам.

| Модель | Правильная культура + рамка / все GT | F1 выбранного протокола | Принятые предметы | Принятая фасоль | Принятый DeepWeeds |
|---|---:|---:|---:|---:|---:|
| YOLO26s из APK | 855 / 1309 | 0,6347 | 1 / 5 | 102 / 133 | 604 / 1581 |
| Пилот YOLO26n | 721 / 1309 | 0,5044 | 2 / 5 | 115 / 133 | 1184 / 1581 |
| Пилот YOLO26n с негативами | 710 / 1309 | 0,4841 | 2 / 5 | 115 / 133 | 427 / 1581 |
| Пилот YOLO26s | 810 / 1309 | 0,5904 | 1 / 5 | 113 / 133 | 321 / 1581 |
| Пилот YOLO26s с негативами | 816 / 1309 | 0,5837 | 2 / 5 | 120 / 133 | 332 / 1581 |
| Имеющийся DEIMv2-N | 773 / 1309 | 0,5018 | 4 / 5 | 132 / 133 | 1329 / 1581 |

Дополнительные строки подтверждены [S](s_report.json), [парой S](s_pair_report.json)
и [DEIMv2-N](deim_report.json). Это сравнение конкретных весов, не рейтинг архитектур.

Использованы все 349 кадров строгого field-val и отдельные val источников
предметов/неизвестных культур. Вход — целый кадр, не GT-вырезка.
После native argmax и class-aware NMS классы отображаются в культуру.
Argmax не ограничивается удобным подмножеством классов.

**Смысл показателя:** предсказания по убыванию confidence сопоставляются
со свободной GT-рамкой при IoU ≥ 0,5 независимо от культуры. Неверная культура
занимает рамку, даёт FP и FN; последующее предсказание не исправляет первый ответ.
Это явно заданный показатель культуры и локализации, не стандартный detector AP
или оценка болезни. Общие культуры определяются до запуска; их GT составляют
знаменатель recall. Старые метки «лист» не объявляются подтверждённым healthy.

Вывод для этого протокола: пилоты N не заменяют действующую S. Негативы снизили
принятие DeepWeeds, но этого нет для фасоли и малого набора предметов. Это не
калиброванный отказ: unknown-сцены могут содержать фоновые растения, а пять
снимков предметов не позволяют оценить надёжность в поле. Исторические ограничения
пересечений источников/split остаются; это не новый независимый тест.

Все модели прогнаны одним CPU runner и preprocessing. Геометрия, native NMS
и порог соответствуют Android; побитовое совпадение ресайзеров PIL и Android
не заявляется. Метод поддерживает будущие ordinary ONNX-пилоты через повторный
`--candidate имя=файл`; приложение и taxonomy_v1 не изменены.

Завершён также первый YOLO26s-пилот без негативов: [отдельный отчёт](s_report.json)
с checkpoint/ONNX SHA, parity, полным сравнением и телефонными временами.
Получены 810 правильных рамок с культурой из 1309 GT, F1 этого протокола 0,5904
против 0,6347 у APK. Принятие источников: предметы 1/5, фасоль 113/133,
DeepWeeds 321/1581. Снижение принятия DeepWeeds сопровождается потерей показателя
на известных культурах; общего выигрыша для замены APK не установлено.
На Redmi медиана только инференса — 434,37 мс (30 измерений после прогрева).
Тренировочные метрики собственной головы и ordinary-head сравнение — разные
проверки. Полная пара представлена в [s_pair_report.json](s_pair_report.json).

Для сравнения с другой архитектурой проверен уже имеющийся **DEIMv2-N**:
[отчёт](deim_report.json). Использованы его native `[1,300,6]`, масштабирование
по отдельным осям и отсутствие NMS, как в Android. Получены 773/1309 правильных
рамок с культурой, F1 данного протокола 0,5018; приняты предметы 4/5,
фасоль 132/133, DeepWeeds 1329/1581. Этот checkpoint не заменяет APK S.
Данные обучения, бюджеты и выбор seed различаются: это сравнение конкретных
артефактов, не доказательство превосходства архитектуры YOLO. Проверка локальная
академическая; веса DEIMv2 с ограниченной лицензией не публикуются.

Оба S-пилота завершены, ordinary ONNX имеет выход `[1,53,3549]` и проходит parity.
Для S с негативами медиана чистого инференса на Redmi — 440,39 мс при 30 измерениях
после прогрева; камера и декодирование сюда не входят. Проверка шла в `.verification`:
БД, фото и настройки сохранились; изменился только служебный `profileInstalled`.
Основная установка не затронута. Вариант с негативами немного улучшил ordinary-head
mAP50–95 относительно своего парного baseline (0,3632 против 0,3452), но ухудшил
F1 общего протокола и принятие неизвестных источников. Эти разные показатели
нельзя подменять друг другом. Один seed и небольшой набор негативов не доказывают
устойчивый эффект. **Действующие веса APK сохраняются.**

Первый S в общем ONNX-сравнении представлен прежним проверенным Windows-экспортом
из `s_report.json`; повторный экспорт того же checkpoint в WSL имеет другой SHA.
Оба прошли parity. Связанные отчёты сохраняют сведения об обоих экспортах;
побитовое равенство разных экспортов не заявляется.

Расчёт [фиксированных порогов](threshold_report.json) использует сохранённые
предсказания всех шести моделей, без нового инференса и без test. Общий baseline
из повторных запусков проверен и учтён один раз. После фильтрации заново считается
сопоставление рамок; принятие unknown считается по кадрам. Если ответов нет,
precision равна `null`, а не доказанной точности. Автоматического выбора порога нет.

Для APK при пороге 0,25 правильны 855/1309 рамок с культурой, при 0,5 — 691/1309,
при 0,75 — 428/1309, при 0,9 — 94/1309. При последнем пороге приняты 1/133 кадров
фасоли и 1/1581 DeepWeeds. При 0,95 unknown-ответов в этих выборках нет, но остаются
лишь 4/1309 правильных рамок. Поэтому высокий confidence сам по себе не решает
задачу надёжного отказа. [График PNG](../../../artifacts/verification/autonomous_20261020/threshold_tradeoff.png)
и [PDF](../../../artifacts/verification/autonomous_20261020/threshold_tradeoff.pdf) — локальные артефакты.

[Разбор ошибок по культурам](field_error_report.json) сохраняет все знаменатели,
пропуски, межкультурные ошибки и предсказания без сопоставленной GT. Например,
картофель: APK 33/83 правильных рамок, S с негативами 26/83; яблоня: 69/119 и 52/119.
Предсказание без GT может быть дублем или неразмеченным растением, поэтому оно
не объявляется подтверждённым диагнозом предмета. Следующий опыт требует
проверки полноты полевой разметки, независимых unknown и отсутствующих классов
`corn__healthy`, `cucumber__bacterial_wilt`, `cucumber__downy_mildew`.

Воспроизведение порогов (путь `--out` должен быть новым):

```powershell
.\ml-pipeline\venv\Scripts\python.exe -X utf8 ml-pipeline/gpu_kit/alternatives/threshold_mobile_comparison.py runs/mobile_comparison_20261020 runs/mobile_s_comparison_20261020 runs/mobile_comparison_deim_20261020 runs/mobile_s_negative_comparison_20261020 --out artifacts/verification/threshold_report.json
```
