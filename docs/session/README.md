# Исторические состояния автоматизаций

JSON и [контрольная точка](CONTINUATION_CHECKPOINT_2026-10-05.md) относятся к старым
сериям. Поля `active`, PID, очереди и указания продолжать не описывают текущую сессию
и не являются разрешением запуска.

Каталог оставлен из-за исторических генераторов и ссылок. Новые журналы сессий
сюда не добавлять. Единственный оперативный вход — [STATUS](../STATUS.md).
