# Данные для огурцов — проверка источников, 3 октября 2026

Приоритет Бориса: картофель, томаты, огурцы. В dataset_clean_v1 огурцов нет. Текущая модель не сможет надёжно распознавать их как отдельную культуру. Источники ниже проверены по страницам авторов; в основное обучение они ещё не включены.

| Источник | Что опубликовано | Совместимость с текущей задачей |
|---|---|---|
| [Cucumber Disease Recognition Dataset, Sultana et al., 2022](https://data.mendeley.com/datasets/y6d3z6f8z9/1) | 1280 исходных полевых изображений, 8 классов, листья и плоды; CC BY 4.0. Есть также готовые аугментации | Полезен для классификации. Для детектора нужно проверить/добавить рамки листьев. Разделять исходные изображения до аугментации |
| [Curated Annotations, Zenodo 16816441, 2025](https://zenodo.org/records/16816441) | Переразметка данных огурцов через Label Studio, 7 категорий. CC BY 4.0 подтверждена metadata API. Два ZIP примерно по 492 МБ | Кандидат для проверки фактического типа аннотаций. Название «annotations» не доказывает наличие пригодных рамок; данные связаны с предыдущим источником, нельзя считать их независимым test |
| [Annotated Cucumber Leaf Dataset, Omarov et al., 2026](https://data.mendeley.com/datasets/mb3vnhpk8z/1) | 500 изображений, 250 здоровых/250 с симптомами, 2705 рамок областей изменения цвета и повреждения; CC BY 4.0 | Это видимые симптомы, не диагноз возбудителя. Рамки описывают повреждённые области, а PlantDoc — целый лист; смешивать их как один тип объектов нельзя |

Следующий шаг: проверить архив и аннотации, отделить листья от плодов, составить отдельную таблицу классов, проверить дубликаты и происхождение снимков. Если есть только категории целого изображения, рассмотреть отдельный классификатор или ручную разметку листьев. Не превращать изображение в рамку целого листа без проверки.

## Фактическая проверка архива Zenodo

Image tags.zip скачан в ml-pipeline/source_candidates/cucumber_zenodo_16816441_tags.zip, 491 706 303 байта. MD5 0c0797650bfcdf66fdf528f5a605909e совпал с метаданными источника. Внутри 7 отдельных архивов: 1129 JPG и 1129 файлов labels, всего 5341 рамка. Есть четыре листовые категории (Anthracnose, Bacterial Wilt, Downy Mildew, Fresh Leaf): 640 изображений и 4022 рамки. В каждом отдельном архиве класс обозначен локальным индексом 0 — при объединении индексы обязательно переназначать. У двух строк плодового класса Pythium Fruit Rot координаты не проходят проверку диапазона.

Выборочная визуальная проверка показывает разницу в смысле рамок: часть охватывает лист целиком, часть — фрагменты одного листа. Поэтому архив сохранён как кандидат; его нельзя автоматически смешать с PlantDoc без согласования разметки. Полная проверка диагнозов, дубликатов и всех рамок ещё не проведена. [Машинный отчёт](cucumber_zenodo_archive_audit.json), [рисунок из четырёх примеров](cucumber_annotation_preview.jpg).

Для картофеля в чистом PlantDoc всего 4 обучающие рамки здорового листа, 7 в val и 0 в test. Рамок класса Potato leaf early blight: 250 train / 54 val / 17 test; Potato leaf late blight: 214 / 22 / 10. Английские имена сохраняем как идентификаторы; русские диагнозы и рекомендации нужно сопоставить с проверенным справочником. Особенно необходимо дополнить здоровый картофель.

Все три источника дают материал для следующего этапа, но сами по себе не доказывают качество на снимках из Беларуси. Для окончательной проверки нужны отдельные местные фотографии.
