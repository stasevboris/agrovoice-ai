# Проверки без локальных моделей

Workflow `.github/workflows/checks.yml` запускает Python-тесты, валидатор KB,
Android JVM-тесты, сборку и lint. Права GitHub ограничены чтением репозитория.
Публикуются только отчёты проверок; веса, фото, датасеты и APK не загружаются.
Сам workflow ещё не запускался на GitHub: push не выполнялся, зелёного бейджа нет.

Локальная проверка выполнена в копии только отслеживаемых файлов, с отдельным
Python venv и `requirements-ci.txt`, без PyTorch. Структура очереди обучения
проверяется всегда; наличие локальных весов, очереди просмотра и Vosk — только
когда они доступны. Результаты и команды — [report.json](report.json).

Android использует настоящие текстовые манифесты и справочник, без файлов ONNX
и Vosk. Полученный APK проверяет компиляцию, не готовность распознавания: его
нельзя использовать вместо установленной полноценной сборки. В Windows
запускался `gradlew.bat`; workflow использует Linux и `bash gradlew` с SDK 37
и JDK 25. Совпадение с новым Ubuntu runner проверится после разрешённого push.
