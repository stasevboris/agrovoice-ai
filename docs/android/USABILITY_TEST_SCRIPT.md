# Проверка понятности и TalkBack — T-03/V-08

Сценарий для человека; автоматические проверки его не заменяют. Подготовлен 20.10.2026,
ещё **не проводился**. Результаты — в `artifacts/usability/` (вне git), сводка — в STATUS.

## Подготовка

- Телефон с отдельной установкой `com.agronomy.phytomonitor.verification` (журнал Бориса не трогать).
  Сборка: `gradlew.bat -PisolateApp=true assembleFieldDebug`, установка `adb install -r`.
- Участник не видел приложение и список фраз. Записать: псевдоним, опыт со смартфоном,
  пользуется ли TalkBack, согласие на запись экрана/звука (только для оценки).
- Наблюдатель не подсказывает. Подсказка, если участник застрял более 60 с, отмечается как помощь.
- Предметы: 2–3 настоящих листа (можно без известного диагноза), один предмет не-лист.

## Задания (одинаковые для режима кнопок, голоса и TalkBack)

| № | Задание участнику | Что считается выполнением |
|---|---|---|
| 1 | «Сфотографируйте лист и узнайте, что решило приложение» | Результат открыт, участник пересказал его своими словами |
| 2 | «Что означает процент у рамки?» | Не называет его вероятностью болезни или долей поражения |
| 3 | «Сохраните осмотр на участке "Теплица 2" с заметкой» | Запись в журнале с участком и заметкой |
| 4 | «Найдите этот осмотр и исправьте заметку» | Изменённая заметка сохранена |
| 5 | «Скажите приложению, что результат неверный, это другая культура» | Оценка кадра «неверно» с исправлением |
| 6 | «Отмените последнее действие» / «не сохраняйте» | Нет лишней записи; участник понял, что отменено |
| 7 | «Сфотографируйте предмет (не лист)» | Участник понимает, что ответ модели не подтверждает диагноз |
| 8 | Голос: «Когда приложение вас слушает?» | Правильно указывает индикатор слушания |

Голосовой режим: участник формулирует команды сам; первую формулировку записать дословно
до любой подсказки. TalkBack: включить до начала, жесты — обычные для участника.
Крупный шрифт: повторить задания 1 и 3 при «Размер шрифта» максимум.

## Что фиксировать по каждому заданию

- выполнено самостоятельно / с подсказкой / не выполнено; время от начала до выполнения;
- для голоса: сказанная фраза, распознанный текст (виден на экране), выполненное действие, ошибочные действия;
- для TalkBack: элементы без понятного названия, порядок фокуса, сообщения, которые не были озвучены;
- цитаты участника о непонятном.

## Ограничения

Один–три участника дают качественные наблюдения, а не долю успешности для всех
пользователей. Не обобщать на полевые условия, шум и перчатки без отдельной проверки.
Автоматическая проверка крупного шрифта (`LargeFontDeviceTest`) показывает только обрезанные
подписи на видимой части экранов.
