# Установка модели и откат — S-04

Android 0.21 продолжает использовать встроенную YOLO26s. Из доверенного локального
каталога можно явно установить подготовленную совместимую YOLO: «проверь
обновления» → «установи обновление модели» либо кнопка в настройках.
Качество модели и право на её распространение остаются условиями подготовки
выпуска; SHA и успешный запуск ONNX не заменяют оценку распознавания.

Перед переключением проверяются размер, SHA, классы/подписи/культуры, типы и
формы входа/выхода, загрузка ORT и пробный расчёт. Native-проверки выполняются
вне UI-потока. Отмена и смена сеанса не должны активировать запоздалую загрузку.
Каталог предложений очищается при смене аккаунта/сервера.
Нехватка места при записи обновления сообщает об освобождении памяти, а не
о сбое сети. Проверка ENOSPC выполнена контролируемой JVM-инъекцией;
свободное место телефона искусственно не исчерпывалось.

Установка меняет выбор **для следующего процесса Android**. В текущем процессе
продолжает работать прежняя модель; переход между экранами не применяет обновление.
Для немедленной активации можно завершить AgroVoice системной командой «Остановить»
и открыть снова. Field использует одну явно установленную модель, lab сохраняет
выбор среди доступных моделей. Подписи в настройках различают доступное обновление
и модель конкретного результата.

При повреждении или невозможности выполнить обновление используются предыдущая
работавшая версия либо встроенная модель. Версия в интерфейсе и происхождение
нового результата соответствуют фактически использованной модели; старые отчёты
не переписываются. Выбранная культура при автоматическом откате сохраняется.
Если резервная модель её не поддерживает, анализ требует уточнения и не выдаёт
«лист не найден» или результат по другим культурам.

Проверки и исходные числа — в [report.json](report.json). На Redmi в отдельном
пакете проверены несовместимый реальный ONNX, установка через программную подачу
распознанных команд и общий исполнитель кнопок,
новые процессы, два последовательных отката, сохранность старого отчёта,
taxonomy в новом отчёте и неподдерживаемая культура. Графы теста синтетические,
с нулевыми выходами; они не являются обученными диагностическими моделями.
Адрес API и настройки после проверки восстановлены. Основная установка обновлена
через `install -r`, её данные сверены с непосредственной резервной копией.

Собраны также подписанные field/lab release с R8, подписи проверены `apksigner`.
Release имеет другой сертификат, чем существующая debug-установка; её не удаляли
ради смены подписи. Публикации APK/весов не было, веса DEIMv2 остаются локальными.
