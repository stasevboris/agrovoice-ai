# Как проверять AgroVoice на телефоне

**Актуальная версия: 0.16, 5 октября.** Добавлена девятая реальная YOLO26m: скажи «модель девять» или нажми кнопку9. Это технический M03, один запуск; итоговые10 M ещё обучаются. M≈1.37с/S≈0.47с/N≈0.17с для готовогоbitmap наNote 7, без камеры/JPEG. [M/APK-проверки](../reports/08_YOLO26M_PILOT_2026-10-05.md). В APK выбрана YOLO26s seed20261004 после десяти полных val, YOLO26n seed20261012 сохранена; все восемь примеров доступны. Камера/галерея/постоянный голос сохраняются. Добавлены заметки с диктовкой и подтверждением, озвучивание, оценки, журнал, участок, поиск/фильтры и экспорт JSON. [Новый отчёт и проверки](FIELD_TOOLS_2026-10-05.md).

Попробуй: «добавь заметку» → продиктуй → «закончить заметку» → проверь текст → «подтвердить». «Результат верный», «результат неверный» или «не уверен» сохраняют твою оценку всего результата. «Открой журнал», «сравни модели», «прочитай результат», «убери рамки» /«покажи рамки» тоже доступны. Во время чтения микрофон приостановлен; остановка кнопкой. Участок и поиск вводятся вручную. Экспорт в журнале открывает системный выбор файла: JSON без самих фото.

Описание старых версий и прежних замеров ниже сохраняет историю. Текущие результаты S/N: [карточка](../experiments/yolo26s_focus_v1/MODEL_CARD.md).


Текущая установленная и проверенная сборка: [APK0.11](../../artifacts/apk/AgroVoice-model-lab-0.11.apk). Постоянное слушание, подтверждённая/немедленная съёмка, галерея со свайпами/номерами/подтверждением и все8 моделей голосом. Шесть инструментальных тестов,98/98 синтезированных команд и0 действий на16 контрольных фразах; это технический контроль, не точность людей в поле. [Полные команды/доказательства](VOICE_CONTROLS_2026-10-04.md), [current_model_lab.json](../../artifacts/apk/current_model_lab.json).

1. Открой AgroVoice AI. Нажми «Сделать фото» или «Из галереи». Десять ранее загруженных снимков находятся в галерее в папке AgroVoice Samples; источники и лицензии сохранены в [описании примеров](../reports/03_ANDROID_IMPLEMENTATION_2026-10-04.md).
2. Сначала выбери «Все культуры», порог0.25 и одну модель. Переключай модели на том же снимке, сохраняя одинаковый порог. При смене модели фото проверяется заново.
3. Кнопки моделей располагаются в несколько строк. Сейчас доступны YOLO11n, YOLO26n, «Лист → MobileNet», «Лист → EfficientNet», «Маска → диагноз», «Ученик MobileNet», YOLO26s и DEIMv2-N. Ученик — MobileNet, обученный дополнительно по ответам более крупного EfficientNetV2-S; сам учитель на телефоне не запускается.
4. «Картофель», «Томат», «Огурец» фильтруют показанные результаты. Если рамка исчезла при фильтре, модель могла перепутать культуру: для сравнения вернись к «Все культуры».
5. Порог определяет, какие результаты показывать. После его изменения нажми «Проверить ещё раз». Более низкий порог добавляет слабые предположения и лишние рамки; более высокий может скрывать настоящие листья.
6. Смотри не только на подпись, но и на рамку: выделен ли именно лист, не пропущены ли другие листья, нет ли нескольких рамок вокруг одного. Для самостоятельной проверки запиши правильность культуры и состояния для каждого листа. Снимки из галереи — примеры, не независимая статистическая проверка.
7. Результат сохраняется автоматически после анализа: фото иJSON с моделью,seed,SHA,рамками,оценками и временем. Постоянный журнал с заметками пока не подключён.

В0.11 включи «Постоянно слушать», дождись «Слушаю постоянно». «Сделай фото» → наведи камеру → «подтвердить»; «сделай фото сразу» снимает без подтверждения. «Открой галерею» → «фото номер три» → просмотр → «подтвердить». Листание: «следующее фото» / «предыдущее фото», кнопки и горизонтальный свайп крупного фото. №1 новое, последнее старое. «Модель один»..«модель восемь» выбирает любой режим; «порог двадцать пять» / «увеличь порог» / «уменьши порог», культуры, «прокрути вниз» / «вверх», помощь/назад доступны голосом. «Стоп» выключает микрофон, «назад» закрывает экран. В фоне запись выключена, при возвращении возобновляется только если переключатель остался включён. Без переключателя после голосового открытия камеры/галереи диалог ограничен2минутами. СистемныйPicker остаётся ручным.

По решению Бориса дальше работаем с **YOLO26n и YOLO26s**. N в APK — seed20261012, лучший по native val среди уже завершённых десяти. S в этой сборке — пилот03, сейчас доводятся десятьS; после выбора окончательных весов выйдет следующая сборка. DETR больше не обучаем. MobileNet, EfficientNet, маска+MobileNet, ученик и DEIMv2-N остаются прежними примерами для самостоятельного сравнения, их серии не объявляются завершёнными десятью обучениями. [Текущий результат](../reports/07_YOLO26_FOCUS_2026-10-04.md).

Ученик немного улучшил обычный MobileNet в первом парном пилоте, но все цепочки и DEIM уступили прямойN по AP и доле правильно найденных/распознанных листьев. ПервыеS впереди; окончательный выигрыш требует десяти повторов. Маска выделяет целый лист, процент поражения не измеряет. Разные схемы score не означают одинаковую вероятность правильного диагноза. Огурец пока «состояние неизвестно»: огуречные болезни не обучены.

На Note 7 в APK0.8 десять серий анализа одного уже декодированного снимка дали около 161 мс для YOLO26n, 306 мс для цепочки MobileNet, 373 мс для EfficientNet, 561 мс для маски + MobileNet, 317 мс для ученика MobileNet, 450 мс для YOLO26s и 256 мс для DEIM. Маска увеличила время примерно в 1,83 раза относительно обычного MobileNet и не улучшила первый пилот на val. Ученик использует ту же архитектуру MobileNet; наблюдаемые 306 и 317 мс имеют перекрывающийся разброс, поэтому рост скорости не заявляется. Учитель при анализе на телефоне не запускается. Чтение файла, камера, сохранение и отрисовка в эти времена не входят. Это десять серий измерения скорости, а не десять обучений. Полные измерения, разброс, память и конкретные веса — [здесь](accuracy_v1/benchmark/summary.json). После изменения выбранных весов показатели пересчитываются.

Для полезной самостоятельной подборки снимай разные растения и дни: один лист крупно, несколько листьев, тень и обычное дневное освещение, здоровые растения и повреждения. Повторные кадры одного растения держим в одной группе, чтобы они не попали одновременно в обучение и проверку. Эти новые снимки не добавлены в текущую замороженную серию.

После10S отдельно проверим [YOLO26m](../experiments/yolo26m_v1/PROTOCOL.md). Пока вAPK нет обученнойM; начальныеCOCO-веса не выдаём за диагноз растений. Все восемь прежних примеров сохраняются.
