# Документы диплома

[Снимок 05.10.2026](2026-10-05/) содержит описание темы/стека, историю разработки,
первоначальный DOCX и [отчёт проверки оформления](2026-10-05/FINAL_QA_REPORT.md).
Это исторические документы. Проверка оформления DOCX не подтверждает научные
утверждения и не делает прежние плановые показатели достигнутыми результатами.

Для следующей редакции читать [аудит](../audits/PROJECT_AUDIT_2026-10-19.md),
[технический отчёт](../architecture/PROJECT_REPORT_2026-10-19.md),
[научные основания](../research/SCIENTIFIC_EVIDENCE_2026-10-19.md) и
[аналоги](../research/ANALOGUES_2026-10-19.md). Структура глав — в [ROADMAP](../ROADMAP.md).

Новые текстовые главы хранить здесь в Markdown; тяжёлые рендеры и рабочие DOCX —
в игнорируемом `artifacts/documents/`. В таблицах испытаний указывать первичный
файл результата, split, версию и условия. Нереализованные сервер, LLM и справочник
описывать как проектирование до появления работающего кода и проверок.
