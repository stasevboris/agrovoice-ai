## 1. Архитектура

### 1.1 Общая схема

```
┌───────────────────────── Телефон (Android, офлайн) ─────────────────────────┐
│  Камера / галерея ──► Распознавание (ONNX) ──► Результат ──► Журнал (Room)  │
│        ▲                     │                    │             │           │
│  Голос / гарнитура ──► Исполнитель действий ◄─────┘        Синхронизация    │
│  (Vosk ASR, TTS)        (кнопки и голос)      Справочник       (WorkManager) │
└──────────────────────────────────────────────────────────────────┬──────────┘
                                                                   │ HTTPS, JWT
┌──────────────── Сервер хозяйства (Docker) ───────────────┐       │
│ nginx ─► FastAPI: sync, auth, web-панель, лента обновлений│◄──────┘
│          PostgreSQL (Alembic), резервные копии            │
└───────────────────────────▲──────────────────────────────┘
                            │ выпуски модели и справочника (SHA-256)
┌─────────── ПК разработки / RX 9060 XT / RTX 5090 кафедры ───────────┐
│ ml-pipeline: наборы → обучение → оценка → ONNX → prepare_model_release│
│ kb/: справочник (Госреестр РБ, Агроатлас) → validate_kb.py            │
└──────────────────────────────────────────────────────────────────────┘
```

**Сборки.** `field` — одна модель для пользователя; `lab` — все модели и инструменты.
Ассеты собирает `android-app/prepare_flavor_assets.py` по `assets/models/manifest.json`;
`.onnx` в git нет, их приносит `fetch_assets.py`. Приватный комплект отказа передаётся
`-PrejectionExperimentDir=…`, в field — дополнительно `-PfieldRejection=true`.

**Стек.** minSdk 26 / targetSdk 37; ONNX Runtime 1.30.0; Vosk 0.3.75; sherpa-onnx 1.13.8 (TTS);
Room 2.8.5; CameraX 1.4.2; WorkManager 2.10.5; Navigation Compose 2.9.5; DataStore 1.1.7.

### 1.3 Конвейер распознавания

```
кадр ─► PhotoQuality ─► letterbox 416 ─► YOLO26 S (ORT) ─► NMS
   ─► [проверяющий] до 8 вырезок ─► DINOv2-small CLS ─► MLP ─► sigmoid(культура − reject) ≥ 0.99588 ?
         да ─► рамка остаётся           нет ─► отказ по этой рамке
   ─► ModelCropPolicy (выбранная культура / «другая культура») ─► AnalysisReport
   ─► экран, голос, журнал, черновик
```

Проверяющий модуль только **удаляет** ответ, культуру или диагноз он не заменяет. Порог подобран для
конкретной S; при смене детектора его надо калибровать заново.
Результаты отказа: [rejection_improved README](../../artifacts/gpu_kit/rejection_improved_20261024/README.md)
(test: верные культура+рамка 350 → 340, FP 165 → 133, фасоль 102/128 → 0/128, DeepWeeds 427/1489 → 0/1489).
Задержка DINO на Redmi — 503,27 мс на вырезку ([STATUS](../STATUS.md)); при восьми вырезках это порядка 4 с
на кадр — арифметическая оценка, не замер полной цепочки.

### 1.4 Голосовой контур

```
микрофон / гарнитура (SCO) ─► Vosk ru ─► VoiceCommands + FreeSpeech (правила)
                                     └─► [нет] локальная LLM-маршрутизация ─► AssistantProtocol (JSON)
   ─► ActionPolicy (допустимо ли в текущем состоянии) ─► ActionDispatcher ─► экран / TTS
```

Кнопки и голос уже идут через один исполнитель. LoRA-пилот роутера проведён на ПК,
мобильного LLM-runtime нет ([исследование](../research/LOCAL_ASSISTANT_2026-10-19.md)).

### 1.5 Сервер (`server/`)

`app/main.py` (FastAPI), `sync.py` (идемпотентная синхронизация, версии осмотров и фото),
`security.py` (JWT), `models.py` + `migrations/` (PostgreSQL, Alembic), `web.py` (панель),
`updates.py` + `prepare_update_feed.py` (лента модели/справочника), `backup.py`, `verify_restore.py`.
`compose.yaml`: api + db + nginx. Последняя проверка — 61 тест OK ([STATUS](../STATUS.md)).

### 1.6 ML-конвейер (`ml-pipeline/`)

| Часть | Что делает |
|---|---|
| `build_allcrops_v1.py`, `build_mix_dataset.py` | наборы allcrops_v1 и allcrops_web_v1 по `allcrops/taxonomy_v1.json` (49 классов, 15 культур, порядок не менять) |
| `gpu_kit/` + `pack_gpu_kit.py` | комплект обучения YOLO26 для 5090: очередь, smoke, ONNX, resumable checkpoints |
| `gpu_kit/rejection/` | признаки DINOv2, головы MLP, калибровка порога, frozen test, экспорт ONNX |
| `gpu_kit/alternatives/` | пилоты D-FINE, INT8, мобильные сравнения |
| `assistant/` | корпус команд, intent-классификатор, LoRA SFT роутера |
| `prepare_model_release.py` | единственный путь выпуска весов: ONNX, SHA256SUMS, карточка модели |

### 4.2 Шаги

1. **Подготовка (агент).** Собрать `03_assistant` и `04_combined_queue`, прогнать smoke на CPU,
   создать `git bundle`. Записать в STATUS.
2. **Копирование (агент, по команде Бориса).** `robocopy` с `/E /R:1 /W:1` в `D:\AgroVoice_5090`;
   источник на F не трогается.
3. **Проверка на D.** Пересчитать SHA-256 каждого файла на D и сравнить с исходником;
   проверить целостность zip (`zipfile.testzip`). Без совпадения — не везти.
4. **Безопасное извлечение диска.**
5. **На кафедре (Борис).** Скопировать с D на внутренний SSD машины, распаковать, `nvidia-smi`
   (нужен драйвер с поддержкой CUDA 12.8 для RTX 50xx), `setup_*`, `check_env`, smoke, затем очередь
   с бюджетом сеанса и запасом на упаковку.
6. **Возврат.** `results_*.zip` → `D:\AgroVoice_5090\RESULTS\<дата>\` вместе с SHA256 и логами.
7. **Дома (агент).** Скопировать в `runs/5090_<дата>/`, сверить SHA, разобрать (M-04/M-05),
   откалибровать отказ, решить по I-4.

**Уточнить у кафедры заранее:** ОС, версию Python 3.10–3.13, драйвер NVIDIA, наличие интернета,
продолжительность сеанса, можно ли оставить машину работать без присмотра.

2. **Снимать R-01 сейчас**, пока ещё есть листья: открытый грунт в марте–апреле в Беларуси не вырастет,
   испытания реально пройдут только в теплице.
3. Договориться о сеансах на 5090 и уточнить параметры машины (раздел 4.2).
4. Найти специалиста для проверки справочника — без него «чем лечить» остаётся `draft`.
5. Гарнитура и 5+ человек для голосовых испытаний.
6. Разрешения: копирование на D, коммиты, отдельно — публикация весов и `git push`.

## 7. Главные риски

| Риск | Что делаем |
|---|---|
| DINO слишком медленный на слабых телефонах | ученик T-3 + INT8; если нет — отказ только в lab |
| Новая S требует новой калибровки отказа | T-2 в том же сеансе 5090, протокол заморожен заранее |
| Сеанс 5090 короткий или сорвался | порядок очереди с отрезаемым концом; домашнее RX-окно до 23:00 по команде Бориса |
| Нет специалиста | справочник честно `draft`, без озвучки дозировок |
| Нет полевого сезона для испытаний | свои снимки сейчас + теплица весной |
| Веб-метки слабые, 17 классов < 30 веб-фото | решения только по field-test; адресный добор с проверкой источника |
