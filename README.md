# AgroVoice AI

Android-приложение для осмотра растений в поле: фото листа → культура и состояние → справка → запись в журнал.
Распознавание и голосовое управление работают на телефоне **без интернета**.

## Что умеет сейчас (APK 0.11–0.16)

* собственная камера на CameraX: «сделай фото» → наведение → «подтвердить» или «сделай фото сразу»;
* детекция листьев и их состояния моделями YOLO26 / YOLO11 через ONNX Runtime прямо на устройстве, рамки и подписи на фото;
* голосовое управление на русском без сети (Vosk): выбор модели, культуры и порога, галерея, прокрутка, помощь;
* галерея снимков (MediaStore) с номерами, свайпами и голосовым подтверждением;
* журнал осмотров: фото и результаты распознавания.

Проверено на Redmi Note 7 (Android 13): шесть инструментальных тестов, 98/98 синтезированных голосовых команд,
0 ложных действий на 16 контрольных фразах. Оценка на реальной речи в поле ещё впереди.

## ML-пайплайн

* данные: PlantDoc (29 классов, CC BY 4.0) после очистки — устранены дубликаты между выборками, согласованы EXIF-повороты и рамки;
  в версии clean v2 добавлены отобранные PlantVillage и датасет огурцов (Zenodo);
* обучение: Ultralytics + PyTorch, серии по 10 seed на архитектуру (YOLO26n, YOLO11n, YOLO26s), сравнение mAP и задержки на телефоне;
* AMD RX 9060 XT: обучение в WSL2 (Ubuntu 24.04) на ROCm 7.2.1;
* автоматизация на PowerShell: запуск и остановка обучения, сборка APK с выбранными весами, замеры на телефоне через ADB.

Пример результата (YOLO26n, clean v1, test): mAP50 0,598 / mAP50–95 0,462; на Note 7 — около 111 мс на граф и постобработку.
Метрики относятся к обнаружению листа с его состоянием, а не к «проценту верных диагнозов». Подробности — в [docs/reports](docs/reports).

## Стек

| Область | Технологии |
|---|---|
| Android | Kotlin 2.2, Jetpack Compose, Material 3, CameraX, MediaStore, minSdk 26 |
| Модели на устройстве | ONNX Runtime Android (FP32), letterbox → граф → NMS |
| Голос | Vosk Android, small-ru-0.22 |
| Обучение | Python 3.12, PyTorch, Ultralytics; ROCm в WSL2 |
| Автоматизация | PowerShell, ADB |

## Структура

```
android-app/   Android-приложение (Gradle, Kotlin)
ml-pipeline/   подготовка данных, обучение, экспорт, замеры на телефоне
docs/          отчёты, исследования, текущее состояние (docs/STATUS.md)
PROJECT_GUIDE.md  подробный журнал решений и экспериментов
```

## Сборка

```bash
cd android-app
./gradlew assembleDebug
```

Веса моделей (`*.onnx`) и голосовая модель Vosk в репозиторий не входят: положите их в
`android-app/app/src/main/assets/models` и `assets/voice` (состав — в `manifest.json`).
Готовые APK планируется публиковать в Releases.
