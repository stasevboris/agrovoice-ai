# Независимая проверка фото и речи — R-01/V-05

Этот вход предназначен для новых реальных материалов AgroVoice. Готовые наборы,
синтетические команды и FLEURS остаются в прежних каталогах и не становятся
независимым пользовательским test. Пустой шаблон — не собранные данные.

Скопируйте `manifest.template.csv` и материалы в игнорируемый каталог
`artifacts/collection/`. CSV сохраняйте в UTF-8. Один ряд — один исходный кадр
или одна запись; ракурсы, вырезки и затемнённые копии не новые наблюдения.
Оригиналы сохраняются, инструмент ничего не удаляет и не перераспределяет.

| Поля | Что записать |
|---|---|
| `id`, `file`, `modality` | Уникальный ID, относительный путь внутри data-root, `image`/`audio` |
| `source`, `source_kind`, `rights` | Происхождение/дата, `real`, основание права использования |
| `split`, `series` | Заранее назначенный train/val/test; неизменный ID серии съёмки/записи |
| `site`, `plant` | Псевдонимы участка и растения для фото; для предмета plant пустой |
| `scenario`, `label`, `label_source` | `known_leaf`: подтверждённый код taxonomy_v1; `unknown_crop`: вид вне таксономии; `unknown_state`: только известная культура; `nonplant`: предмет. Источник метки/специалист обязателен |
| `light`, `pair` | Условие света; для пары — общий ID, реальные кадры `light` и `shadow` того же растения |
| `speaker`, `consent`, `consent_ref` | Псевдоним говорящего, `evaluation` либо `training_and_evaluation`, ссылка на локальную запись согласия |
| `transcript`, `expected_actions`, `context` | Для речи — ручная расшифровка, JSON-список объектов `action`/`value` (`[]` — отсутствие действий) и относительный путь к JSON состояния приложения |

Изображения проверяются Pillow, звук принимается как несжатый PCM WAV. Храните
оригинальные записи рядом с конвертированными, если исходный формат другой.
Для аудио scenario — `command` или `background`. К каждой команде сохраните рядом
исходное состояние приложения в JSON протокола `AssistantProtocol`: без экрана,
наличия результата и pending нельзя определить правильное действие. Записывайте
человеческую свободную формулировку до демонстрации подсказок; ошибки ASR сохраняйте
рядом с ручной расшифровкой. Фоновые разговоры — только с соответствующим согласием.
Согласие на оценку не разрешает обучение. Имена и контакты не кладите в manifest.

Все кадры одного растения, участка, серии и пары остаются в одном split.
Для независимой речи говорящие тоже не пересекаются между split. Назначайте split
до подбора модели; один общий участок даёт только один split, а не искусственный
test из соседних кадров. Если происхождение или метка сомнительны, исключите ряд,
сохранив причину в отдельном CSV исключений. Не называйте неизвестный вид предметом.

```powershell
.\ml-pipeline\venv\Scripts\python.exe -X utf8 ml-pipeline/collection/validate_collection.py artifacts/collection/manifest.csv --data-root artifacts/collection --out artifacts/collection/report.json
```

Код возврата 2 означает ошибки или отсутствие данных. Проверяются файлы и точные
дубликаты, группы, происхождение полей, разрешение обучения, тип метки и пары света.
Человек отдельно подтверждает согласия, метки и почти-дубликаты. После проверки
заморозьте CSV и исходники test; настройку порогов ведите только на val.

Оценка полной цепочки выполняется на исходных фото с одним подтверждённым целевым листом/предметом, не на идеальных вырезках. Это оценка решения, не mAP детектора; сцены с несколькими разными состояниями требуют отдельной разметки каждого листа.
Для каждого ID сохраняйте фактическое принятое решение/отказ и исходные выходы
модели. Для речи сравнивайте **исполненные** действия после Android-политики,
а не только предложенный JSON. Команда оценки и формат выходов — в `evaluate_collection.py`.
```powershell
.\ml-pipeline\venv\Scripts\python.exe -X utf8 ml-pipeline/collection/evaluate_collection.py artifacts/collection/manifest.csv artifacts/collection/predictions.jsonl --data-root artifacts/collection --split val --out artifacts/collection/evaluation.json
```

JSONL для фото содержит `id`, булев `accepted` и `label` при принятом ответе;
для речи — `id`, `actions` (список фактически исполненных объектов action/value).
Пустой ответ не подменяется пропущенной строкой. ID должны покрывать весь выбранный
split ровно один раз. Для неизвестного состояния принятое назначение состояния
считается ошибкой; выделенная культура сама по себе не является принятым диагнозом.

Отдельно фиксируйте освещение, предметы, неизвестные культуры/состояния, пропуски,
ложные действия, риск среди принятых результатов и долю принятых. Малый набор или
нулевая ошибка на нём не доказывают надёжности в поле.
